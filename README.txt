ركن المعلم — خطوات الرفع على GitHub Pages

1) ارفع محتويات هذا المجلد كما هي إلى مستودع موقعك: index.html + مجلد img + مجلد tools
   (يبقى مجلدا img و tools بجانب index.html). ملف comments-backend وملف التعليمات للمرجع فقط.
2) Settings ← Pages ← اختر الفرع main والمجلد root ← Save.
3) افتح الرابط. قراءة الشيتات تعمل لأن الصفحة مفتوحة من موقع عادي.
4) لتفعيل التعليقات الحقيقية اتبع: تعليمات-التعليقات.txt

ملاحظات:
- بطاقة «نرد الحظ» تفتح رابط أداة النرد في claude.ai وقد لا يفتح لغيرك إلا إذا شاركته.
- لتعديل الصفوف: tools/attendance.html ← القائمة CLASSES أعلى السكربت.
