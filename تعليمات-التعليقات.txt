تفعيل التعليقات (يرى الجميع، والمشرف فقط يحذف أو يوقف الخاصية)
================================================================

الموقع على GitHub لا يحفظ بيانات، لذلك تُحفظ التعليقات في ملف Google Sheet عندك
عبر تطبيق صغير (Google Apps Script). مجاني، ويستغرق نحو ٥ دقائق:

1) أنشئ ملف Google Sheet جديداً (اسمه مثلاً: تعليقات ركن المعلم).
2) من القائمة: الإضافات (Extensions) ← Apps Script.
3) احذف أي كود موجود والصق محتوى الملف  comments-backend/Code.gs  ثم احفظ.
4) كلمة مرور المشرف:
   - أيقونة الترس «إعدادات المشروع» (Project Settings) ← Script Properties
   - Add script property:  الاسم  ADMIN_PASSWORD  والقيمة  كلمة مرور قوية تختارها. احفظ.
5) انشر التطبيق: Deploy ← New deployment ← النوع Web app
   - Execute as: Me (أنا)
   - Who has access: Anyone (أي شخص)
   ثم Deploy ووافق على الأذونات. انسخ رابط Web app (ينتهي بـ /exec).
6) افتح index.html في موقعك وابحث عن السطر:
      var COMMENTS_API='';
   والصق الرابط بين علامتي الاقتباس، ثم ارفع الملف على GitHub.

الاستخدام:
- أي زائر: يضغط أيقونة 💬 في بطاقة الأداة ويقرأ التعليقات ويكتب تعليقاً.
- المشرف: يضغط «🔐 المشرف» أسفل الصفحة ويدخل كلمة المرور، فتظهر له أزرار «🗑 حذف»
  على كل تعليق، وزر «إيقاف خاصية التعليقات للجميع» (تختفي أيقونات التعليقات عن الزوار،
  ويمكنه إعادة تشغيلها متى شاء).
- يمكنك أيضاً حذف أي تعليق مباشرة من ورقة Comments في الشيت.

ملاحظات:
- عند تعديل كود Code.gs لاحقاً يجب عمل Deploy ← Manage deployments ← Edit ← New version.
- إن تركتَ COMMENTS_API فارغاً يعمل الموقع بوضع تجريبي (تعليقات على جهازك فقط، وكلمة مرور المشرف admin).
